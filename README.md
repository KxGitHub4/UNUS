# UNUS

UNUS 是一个基于 React Native + TypeScript 构建的轻量、高效的 UI 工具与组件平台。

## 技术栈

- **Core**: React Native (0.88+) / Expo SDK 58
- **Language**: TypeScript 6.0
- **Framework**: React 19

## 快速开始

### 依赖安装

```bash
npm install
```

### 启动项目

```bash
# 启动 Expo 开发服务
npm start

# Web 预览
npm run web

# Android
npm run android

# iOS (需 macOS 环境)
npm run ios
```

## 目录结构

```text
UNUS/
├── App.tsx          # 根组件入口
├── index.ts         # 入口引导
├── app.json         # Expo 配置
├── tsconfig.json    # TypeScript 配置
└── assets/          # 静态资源文件
```
